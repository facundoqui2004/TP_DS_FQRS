=======================================================================
           📖 INSTRUCCIONES DE USO - PROYECTO EL SÚPER GESTOR 📖
=======================================================================

Este proyecto consta de dos entornos principales:
1. Backend (API en Node.js + TypeScript + MikroORM + MySQL)
2. Frontend (Aplicación en React + Vite + Tailwind CSS)

-----------------------------------------------------------------------
📌 REQUISITOS PREVIOS
-----------------------------------------------------------------------
* Node.js instalado (versión 18 o superior).
* Docker Desktop instalado y ejecutándose (para la base de datos).
  En caso de no usar Docker, debes disponer de una instancia local de
  MySQL corriendo en el puerto 3309 con las credenciales indicadas abajo.

-----------------------------------------------------------------------
🚀 CÓMO INICIAR EL PROYECTO
-----------------------------------------------------------------------
La forma más fácil de iniciar ambos entornos es haciendo doble clic en 
el archivo:
    ▶ iniciar_entornos.bat

Este script automatizará los siguientes pasos:
1. Copiará el archivo `.env.txt` como `Backend/.env` para configurar las
   credenciales de la base de datos.
2. Iniciará el contenedor Docker de MySQL en el puerto 3309.
3. Instalará las dependencias necesarias en Backend y Frontend.
4. Levantará el Backend en una nueva consola (puerto 3000).
5. Levantará el Frontend en otra nueva consola (puerto 5173 o 5174).

-----------------------------------------------------------------------
🔧 INICIO MANUAL (Por si falla el .bat)
-----------------------------------------------------------------------
Si prefieres iniciar los entornos de forma manual, sigue estos pasos:

1. CONFIGURACIÓN INICIAL:
   Copia el archivo `.env.txt` de la raíz en la carpeta `Backend`
   y cámbiale el nombre a `.env`.

2. BASE DE DATOS:
   Abre una consola en `Backend/docker` y ejecuta:
     docker-compose up -d mysql

3. BACKEND:
   Abre una consola en `Backend` y ejecuta:
     npm install
     npm run dev

4. FRONTEND:
   Abre una consola en `Front` y ejecuta:
     npm install
     npm run dev
